# Products, pricing, and included items

## Identity Kit

### Identity Kit Core
- Price: $79
- Includes:
  - Brand Brief (1-page PDF)
    - Brand anchor sentence (north-star positioning line)
    - Brand overview
    - Ideal customer
    - Core transformation / promise
    - Values and positioning cues
    - Brand story angle
    - Differentiation snapshot
  - Brand Style Guide (2-page PDF, visual-first)
    - Palette overview
    - Visual direction summary
    - Typography direction
    - Style principles
    - Do / avoid guidance
    - Practical usage notes (where to apply first)
  - Voice and Content Playbook (2-3 page PDF, writing guidance)
    - Tone profile
    - Voice guardrails
    - Messaging themes
    - Sample phrases and language cues
    - Writing do / avoid guidance
  - 30-Day Quick Start Checklist (1-page PDF rollout plan)
    - Week 1: foundational actions
    - Week 2: messaging updates
    - Week 3: visual rollout
    - Week 4: consistency checks

### Identity Kit Pro
- Price: $149
- Includes:
  - Everything in Identity Kit Core, with deeper synthesis/personalization across audience, tone, story, and differentiation
  - Content Starter Pack (practical copy asset), including:
    - One-liner / brand summary options
    - Homepage messaging directions
    - Brand bio / about intro
    - Social bio options
    - Caption starters
    - Content pillar prompts
    - CTA suggestions
  - Pro-only email voice templates in expanded output (per current spec)
  - Practical difference vs Core: Core is strategy + direction + implementation checklist; Pro adds reusable, ready-to-adapt messaging and copy assets
